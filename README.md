# SmartTV

ТВ-лаунчер для Windows: YouTube (ТВ-версия), RUTUBE, VK Видео, свои сайты и локальные видео. Всем можно управлять с телефона по Wi-Fi.

```
desktop/   приложение для Windows (Electron)
android/   пульт для Android (Kotlin) — следующий этап
docs/      протокол связи пульта и ПК
```

## Запуск

Нужен Node.js 20+.

```bash
cd desktop
npm install
npm start
```

Установщик для Windows (`desktop/dist/`):

```bash
npm run dist
```

При первом запуске Windows спросит доступ к сети: разрешите его для **частных сетей**, иначе телефон не увидит ПК.

## Управление с клавиатуры (и с любого USB/Bluetooth-пульта)

| Клавиша | Действие |
|---|---|
| Стрелки | перемещение |
| Enter | открыть / OK |
| Esc, Browser Back | назад |
| Ctrl+H, Browser Home | на главный экран |
| F11 | во весь экран |

В плеере локальных видео: Enter — пауза, ←/→ — 10 секунд, ↑/↓ — 1 минута. Место остановки запоминается.

## Пульт с телефона (пока веб-версия)

1. Главный экран → **Настройки → Подключить пульт**.
2. Отсканируйте QR-код камерой телефона (телефон в той же Wi-Fi сети). Или откройте указанный адрес и введите PIN.
3. Телефон запомнится, PIN больше не нужен. Отвязать его можно в том же окне.

Что есть в пульте: крестовина, OK, Назад, Домой, пауза и перемотка, громкость Windows, тачпад-мышь (тап — клик, двумя пальцами — прокрутка), ввод текста и отправка ссылки на ТВ.

## Как это устроено

- **YouTube** открывается как `youtube.com/tv` с User-Agent телевизора Samsung, поэтому выглядит и управляется как на Smart TV. Вход в аккаунт — через код на `yt.be/activate`.
- **RUTUBE, VK Видео и свои сайты** открываются как обычные сайты. Чтобы ходить по ним стрелками, в страницу добавляется навигация с подсветкой фокуса. Для сложных мест есть тачпад.
- Входы в аккаунты сохраняются между запусками.
- Мышь и громкость управляются через системный API Windows: фоновый процесс PowerShell, никаких нативных модулей.
- Настройки лежат в `%APPDATA%\smarttv\config.json`.
- Протокол связи с пультом описан в [docs/protocol.md](docs/protocol.md).

## Известные ограничения

- Если YouTube в вашей сети недоступен без VPN, SmartTV покажет ошибку. Приложение использует системные настройки прокси и VPN.
- Плеер локальных файлов играет то, что умеет Chromium: MP4 (H.264/AAC), WebM, частично MKV. HEVC/H.265, AC3/DTS и AVI не поддерживаются.
- Приложения из Google Play пока не поддерживаются (план: плитки, запускающие их через эмулятор).
